# sand-simulation

`core` — ядро симуляции Cats of Sands на Rust и Bevy ECS. Оно загружает конфигурацию, владеет игровым миром и предоставляет браузеру API через WASM. JavaScript отвечает за ввод и отрисовку Canvas.

## Как работает симуляция

1. `Session::new` получает упорядоченные слои YAML. Модуль `config` объединяет сущности по ID, а компоненты по типу, и проверяет итоговые данные до создания мира.
2. `Session::advance` получает прошедшее время в секундах и выполняет накопившиеся шаги по 1/60 секунды. Система `move_sprites` обновляет положение объектов с `Sprite` и `Speed`.
3. `Session::snapshot` возвращает данные видимых объектов для отрисовки. При клике браузер передаёт ID цели в `Session::click`. Наблюдатель `apply_click_color` обрабатывает направленное событие `Clicked` и меняет цвет цели с компонентами `Sprite` и `ClickColor`.

Формат YAML и пример аддона описаны в разделе «Конфигурация» корневого README.

## Как расширять ядро

- **Компонент.** Добавьте файл в `src/components/`. Объявите тип Bevy и загрузчик, который десериализует и проверяет поля, затем возвращает операцию вставки через `prepare`. Подключите модуль и зарегистрируйте имя типа в `src/components.rs`. Простой пример — `Speed`.
- **Система.** Добавьте файл в `src/systems/`, подключите его в `src/systems.rs` и зарегистрируйте функцию в расписании в `Session::from_config`.
- **Наблюдатель.** Добавьте файл в `src/observers/`, подключите его в `src/observers.rs` и зарегистрируйте функцию через `world.add_observer` в `Session::from_config`. Для реакции на конкретную сущность используйте `EntityEvent`, как в примере `Clicked`.
