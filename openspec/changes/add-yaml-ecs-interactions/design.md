## Context

Rust владеет миром Bevy, а JavaScript рисует снимки мира на Canvas. Слои YAML уже объединяются до десериализации и валидации.

## Goals / Non-Goals

Сохранить совместимость старых аддонов и фиксированный шаг движения. Область изменения ограничена одним направленным взаимодействием и компонентами, зарегистрированными в Rust.

## Decisions

- Использовать словарь типов, чтобы рекурсивное объединение YAML сохраняло поля компонентов, которые аддон не переопределяет.
- Искать загрузчик по имени компонента в реестре Rust. Загрузчик десериализует и проверяет данные своего типа, затем возвращает операцию вставки. Мир создаётся после успешной проверки всех компонентов.
- Хранить стабильный ID сущности отдельно от компонентов отображения. Снимок возвращает тот же формат и служит источником геометрии для выбора объекта по клику. JS передаёт ID в WASM, Rust направляет `EntityEvent` через Bevy Observer.
- Компонент `ClickColor` задаёт цвет реакции. Обработчик запрашивает его и `Sprite` только у цели события.

## Risks / Trade-offs

- Размер Canvas может отличаться от размера в CSS. Координаты клика переводятся в координаты Canvas перед проверкой последнего отрисованного снимка.
- При смешивании форматов явно заданный компонент целиком заменяет соответствующее описание прежнего формата. Остальные компоненты можно задавать независимо.
