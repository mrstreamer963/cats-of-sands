## Context

Rust владеет миром Bevy, а JavaScript рисует снимки на Canvas. Слои YAML объединяются до итоговой десериализации и валидации.

## Goals / Non-Goals

Сделать состав YAML-типов явным и дать Rust и WASM общий пошаговый доступ к симуляции. Зафиксировать порядок команд, адресацию экземпляров и границу между ECS и Canvas.

## Decisions

- Хранить описание типа как словарь по именам компонентов. В списочной записи сущности сначала извлекать операцию, затем объединять остальные ключи как компоненты. Загрузчик из реестра Rust валидирует данные и возвращает повторно используемую операцию вставки компонента.
- В браузере проверять `depends` выбранных аддонов и применять первый готовый аддон в порядке каталога. YAML-слои передаются ядру в полученном порядке.
- Создавать экземпляры из проверенных описаний типов и выдавать возрастающий `SimId` через счётчик сессии. Индекс связывает ID с ECS-сущностью и именем типа.
- Хранить очередь команд по номеру тика. `Simulation::step` исполняет команды перед движением, а `Session::advance` накапливает время кадра. Клик направляет Bevy `EntityEvent` целевой сущности. Наблюдатель меняет цвет и записывает событие, только если цвет изменился.
- Хранить координаты, радиус и скорость в `Fixed` формата Q32.32. Преобразовывать числа YAML при загрузке, обновлять `Position` у сущностей с `Speed` целочисленно, а значения для Canvas сериализовать в числа JavaScript.
- В `EntitySnapshot` экспортировать `id`, `type` и независимые необязательные поля `position` и `sprite` из соответствующих ECS-компонентов. Canvas отбирает сущности с обоими полями и проверяет попадание по последнему отрисованному снимку и передаёт в WASM ID экземпляра.

## Risks / Trade-offs

- Старые конфигурации требуют явного переноса полей в компоненты. Поставляемые сцена и аддон уже используют этот формат.
- Зависимость может изменить относительный порядок слоёв. При конфликте полей действует порядок фактического применения.
- Координаты клика нужно переводить из CSS-координат в координаты Canvas. Изменение цвета становится видимым после ближайшего шага.
