## ADDED Requirements

### Requirement: Компоненты сущностей в YAML

Итоговое описание каждого типа сущности SHALL задавать компоненты непосредственно по их именам. Поддерживаемые имена включают `Position`, `Sprite`, `Speed` и `ClickColor`. Координаты `x` и `y` SHALL задаваться в `Position`, радиус и цвет — в `Sprite`. Поля одного компонента SHALL объединяться рекурсивно. Тип без компонентов SHALL допускать пустой словарь. Обёртка `components` и поля `position`, `radius`, `color` и `speed` непосредственно в описании типа SHALL отклоняться.

#### Scenario: Переопределение поля компонента

- **WHEN** аддон меняет цвет `Sprite` существующей сущности, сохраняя остальные поля компонента
- **THEN** сущность получает новый цвет и сохраняет исходный радиус и отдельный компонент `Position`

#### Scenario: Неизвестный компонент

- **WHEN** итоговая конфигурация содержит неизвестное имя компонента
- **THEN** запуск завершается ошибкой с путём до неизвестного компонента

#### Scenario: Неявное описание компонента

- **WHEN** объединённая конфигурация содержит `speed` непосредственно под именем типа
- **THEN** запуск завершается ошибкой с именем поля и путём до типа

#### Scenario: Устаревшая обёртка компонентов

- **WHEN** итоговое описание типа содержит ключ `components`
- **THEN** запуск завершается ошибкой с указанием перенести компоненты непосредственно в описание типа

## MODIFIED Requirements

### Requirement: Порядок и правила объединения

Приложение SHALL применять выбранные аддоны поверх базового YAML. На каждом шаге SHALL применяться первый по порядку каталога аддон, у которого уже применены все зависимости. Коллекция описаний сущностей SHALL объединяться по строковому имени типа. Поля объектов SHALL объединяться рекурсивно, списки SHALL заменяться целиком, а конфликтующие значения SHALL заменяться значением более позднего слоя. В списочных записях сущностей ключ операции SHALL определять действие и имя типа. Остальные ключи SHALL обрабатываться как имена компонентов.

#### Scenario: Частичное переопределение и добавление

- **WHEN** выбранный аддон меняет `Speed.value` базового типа и объявляет новый тип
- **THEN** базовый тип получает новую скорость и сохраняет исходную стартовую позицию
- **AND** итоговая конфигурация содержит оба типа

#### Scenario: Конфликт двух независимых аддонов

- **WHEN** два выбранных аддона без зависимостей меняют одно поле или один список
- **THEN** итоговое значение поля или списка берётся из аддона, который расположен позже в каталоге

#### Scenario: Зависимость расположена позже в каталоге

- **WHEN** оба аддона выбраны и первый по каталогу зависит от второго
- **THEN** второй применяется раньше первого

#### Scenario: Аддон выключен

- **WHEN** аддон присутствует в каталоге, но его галочка снята
- **THEN** его данные не влияют на итоговую конфигурацию

### Requirement: Статический каталог аддонов

Стартовый экран SHALL загружать редактируемый вручную статический каталог `config/addons.json`. Каждая запись SHALL содержать уникальный строковый `id`, отображаемое `name` и `path` к YAML относительно корня сайта. Запись может содержать `depends` со списком строковых ID. Порядок каталога SHALL определять порядок отображения и приоритет между аддонами, готовыми к применению. Приложение SHALL отклонять запуск при некорректном списке зависимостей выбранного аддона, отсутствующей выбранной зависимости или цикле. Необязательные метаданные `addon` SHALL исключаться из игровых данных при объединении слоёв.

#### Scenario: Обновление каталога на хостинге

- **WHEN** автор публикует новый YAML и добавляет запись о нём в статический каталог
- **THEN** при следующей загрузке обновлённого каталога стартовый экран показывает галочку с именем из записи

#### Scenario: Переименование аддона

- **WHEN** автор меняет имя или путь записи, сохраняя ID
- **THEN** стартовый экран восстанавливает выбор по прежнему ID

#### Scenario: Зависимость не выбрана

- **WHEN** выбранный аддон требует аддон, который отсутствует в каталоге или выключен
- **THEN** запуск завершается ошибкой с именем аддона и необходимой зависимости

#### Scenario: Цикл зависимостей

- **WHEN** выбранные аддоны образуют цикл зависимостей
- **THEN** запуск завершается ошибкой со списком аддонов, чья загрузка заблокирована
