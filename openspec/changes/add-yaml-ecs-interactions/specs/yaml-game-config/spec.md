## ADDED Requirements

### Requirement: Компоненты сущностей в YAML

Конфигурация SHALL принимать словарь `components` по именам поддерживаемых типов `Sprite`, `Speed` и `ClickColor`. Поля одного типа SHALL объединяться рекурсивно по существующим правилам слоёв. Записи в прежнем формате SHALL сохранять прежнее поведение. Явно заданные компоненты `Sprite` и `Speed` SHALL иметь приоритет над соответствующими полями прежнего формата.

#### Scenario: Переопределение поля компонента

- **WHEN** аддон меняет цвет `Sprite` существующей сущности, сохраняя остальные поля компонента
- **THEN** сущность получает новый цвет и сохраняет исходную позицию и радиус

#### Scenario: Неизвестный компонент

- **WHEN** итоговая конфигурация содержит неизвестное имя компонента
- **THEN** запуск завершается ошибкой с путём до неизвестного компонента
