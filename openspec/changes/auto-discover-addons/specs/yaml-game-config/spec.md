## ADDED Requirements

### Requirement: Статический каталог аддонов

Стартовый экран SHALL загружать редактируемый вручную статический каталог `config/addons.json`. Каждая запись SHALL содержать уникальный строковый `id`, отображаемое `name` и `path` к YAML относительно корня сайта. Порядок записей SHALL определять порядок отображения и применения. Необязательные метаданные `addon` SHALL исключаться из игровых данных при объединении слоёв.

#### Scenario: Обновление каталога на хостинге

- **WHEN** автор публикует новый YAML и добавляет запись о нём в статический каталог
- **THEN** при следующей загрузке обновлённого каталога стартовый экран показывает галочку с именем из записи

#### Scenario: Переименование аддона

- **WHEN** автор меняет имя или путь записи, сохраняя ID
- **THEN** стартовый экран восстанавливает выбор по прежнему ID
