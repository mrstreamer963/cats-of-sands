## Context

Браузер загружает общий каталог перед отображением галочек и читает игровой YAML выбранных аддонов при запуске. Ядро принимает упорядоченные YAML-слои. Формат каталога и адресация файлов меняются на стороне браузера.

## Goals / Non-Goals

**Goals**

- Держать данные, метаданные и ресурсы одного аддона в переносимой папке.
- Присваивать пакету воспроизводимый хэш до публикации.

**Non-Goals**

- Сохранение партий, хранение прошлых версий пакетов и загрузка медиа для воспроизведения.

## Decisions

- Каталог содержит только имена папок, например `["desert-companion"]`. Автор задаёт состав и приоритет публикации в одном файле. Манифест внутри папки владеет метаданными, поэтому переименование папки и изменение названия отделены от стабильного ID.
- Загрузчик читает и проверяет все манифесты перед выводом галочек. Результаты сохраняют порядок исходного массива независимо от порядка ответов. Сортировка зависимостей использует существующий алгоритм. Браузер передаёт YAML в Rust в полученном порядке.
- Путь в манифесте состоит из относительных сегментов. Абсолютные адреса, пустые сегменты, `.`, `..`, обратная косая черта, URL-экранирование и компоненты запроса или фрагмента отклоняются. Подготовка пакета проверяет существование YAML и отклоняет символические ссылки.
- Node-инструмент обходит файлы рекурсивно и сортирует относительные пути с разделителем `/` по их байтам UTF‑8. Для каждого пути поток SHA‑256 получает длину пути, байты пути, длину содержимого и байты содержимого. Длины кодируются как беззнаковые 64-битные числа в big-endian. Для `resource.json` берётся UTF‑8 JSON без пробельного форматирования, с сортировкой ключей объектов на всех уровнях по байтам UTF‑8 и с сохранением порядка массивов. Верхнеуровневое поле `sha256` исключается перед сериализацией. Это позволяет повторно вычислять хэш после записи манифеста и учитывает переименования файлов.
- Подготовка хэшей запускается перед dev/build и доступна отдельно для публикации статических файлов. Браузер проверяет формат поля `sha256` и сохраняет его в данных загруженного аддона для будущей ссылки на версию.

- Базовый манифест читается при запуске сцены. База и пакеты задают пути к YAML через `layers` относительно своих папок. В ядро сначала передаются слои базы, затем слои каждого выбранного пакета в порядке зависимостей.

## Risks / Trade-offs

- Каталог теперь требует отдельный запрос на каждый манифест. Запросы можно выполнять параллельно, сохраняя порядок каталога.
- Хэш описывает пакет на момент подготовки. Публикация изменённых файлов вместе со старым манифестом даст неверный идентификатор версии. Документация публикации должна требовать пересчёта после любого изменения пакета.

## Migration Plan

Перенести YAML демонстрационного аддона в `config/addons/desert-companion/`, вынести метаданные в `resource.json` и сохранить прежний ID. Обновить каталог, загрузчик и Rust-фикстуру в одном изменении. Публиковать каталог, папки и браузерный код одним релизом. Для отката использовать предыдущий комплект статических файлов и кода.
