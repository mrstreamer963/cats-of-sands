## 2. Конфигурация и симуляция

- [x] 2.1 Реализовать разбор именованных YAML-слоёв, рекурсивное слияние отображений и замену списков. Добавить типизацию и итоговую валидацию с диагностикой по полям.

## 3. Браузерный интерфейс

- [x] 3.1 Сделать экран запуска с галочками, сохранением выбора в `localStorage` и восстановлением доступных ID. Загружать базовый YAML и выбранные аддоны в порядке каталога, отображать ошибки на экране запуска.
- [x] 3.2 Подключить цикл кадров и Canvas 2D. При повторном запуске заменить предыдущую сессию и её цикл кадров после успешной инициализации новой сессии.
