## Context

Загрузчик уже объединяет именованные типы и подготавливает компоненты для создания экземпляров.

## Goals / Non-Goals

Стартовый мир собирается из каталога и списка расстановки. Управление и игровая логика находятся за пределами изменения.

## Decisions

- Каталог использует записи `type: CAT` в стиле OXCE. Имена поставляемых типов записаны заглавными буквами. Загрузчик сопоставляет имена с учётом регистра.
- Правила объединения компонентов используются и для каталога. Аддоны дописывают расстановки в порядке загрузки. Повторяющийся тип допустим, поскольку каждая запись задаёт отдельный экземпляр.
- Загрузчик проверяет ссылки и подготавливает координаты до создания мира. Для старого формата `entities` без каталога и расстановки сохраняется прежний запуск.

## Risks / Trade-offs

Смешивание форматов оставляет неясным состав стартовой сцены. При миграции сцены и её аддонов каталог и расстановку нужно перенести вместе.
