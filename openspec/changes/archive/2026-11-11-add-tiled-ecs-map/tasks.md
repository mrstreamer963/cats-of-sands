## 2. Сетка и движение в симуляции

- [x] 2.1 Передать описание сетки в Rust/WASM, проверить границы и расстановку, создать сущности земли и стен и индекс клеток. Сохранить запуск YAML-карт без Tiled.
- [x] 2.2 Добавить команду урона стене по клетке на следующий тик. При разрушении обновить индекс и снимок стен в том же тике. Проверить разрушение над проходимой и непроходимой землёй.
- [x] 2.3 Реализовать детерминированный поиск пути по четырём соседям, движение по маршруту и остановку при недоступной цели. Проверить проход в стене, новое направление после разрушения, ограничение автоматического движения и смену приказа.
- [x] 2.4 Связать групповое построение с размерами сетки и доступностью мест. Проверить распределение целей у края и возле стены, а также остановку юнитов без достижимых мест.
