## Context

Vite обслуживает и копирует файлы из `public`. Rust разбирает игровые слои при запуске симуляции.

## Goals / Non-Goals

Разрешить обновление каталога и YAML при публикации отдельных статических файлов.

## Decisions

- `public/config/addons.json` содержит упорядоченный массив записей с `id`, `name` и `path`. Vite поставляет его вместе с остальными статическими файлами.
- Стартовый экран ждёт каталог перед включением кнопки запуска. Выбор хранится по ID, а выбранные YAML загружаются при запуске игры.
- Rust удаляет необязательный ключ `addon` из дополнительных слоёв перед слиянием.

## Risks / Trade-offs

- При добавлении аддона автор публикует YAML и обновляет JSON. Порядок записей в JSON определяет приоритет слияния.
