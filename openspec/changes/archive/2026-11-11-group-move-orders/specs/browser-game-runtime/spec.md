## ADDED Requirements

### Requirement: Выделение и групповое перемещение

Обычный клик по юниту SHALL выделять только его. Shift + клик по юниту SHALL менять его присутствие в выделении. Проверка попадания SHALL использовать положение юнита в последнем отрисованном кадре. Выделенные юниты SHALL иметь видимый контур. При повторном запуске сцены выделение SHALL сбрасываться.

#### Scenario: Изменение выделения

- **WHEN** игрок кликает по одному юниту, затем с Shift кликает по второму
- **THEN** оба юнита выделены
- **AND** повторный Shift + клик по второму снимает выделение только с него

#### Scenario: Общий приказ

- **WHEN** игрок с несколькими выделенными юнитами кликает по пустому месту
- **THEN** браузер ставит один приказ на ближайший тик
- **AND** ядро назначает каждому способному двигаться юниту отдельную конечную позицию вокруг точки клика, в порядке `SimId`
- **AND** каждый юнит движется со своим `Speed` и останавливается по прибытии

#### Scenario: Точка сбора рядом с краем

- **WHEN** построение у края сцены не помещается вокруг точки клика, но помещается в самой сцене
- **THEN** ядро сдвигает построение внутрь сцены, сохраняя расстояния между местами

#### Scenario: Один участник приказа

- **WHEN** в приказе только один способный двигаться юнит
- **THEN** он движется точно к указанной точке

#### Scenario: Остановка по прибытии

- **WHEN** юнит достигает цели одиночного или группового приказа
- **THEN** юнит остаётся в точке назначения на следующих тиках до нового приказа

#### Scenario: Клик по земле без выделения

- **WHEN** игрок кликает по пустому месту без выделения
- **THEN** приказ перемещения не создаётся

## MODIFIED Requirements

### Requirement: Реакция сущности на клик

Попадание SHALL определяться по положению объекта в последнем отрисованном кадре. Обычный клик по видимому объекту SHALL поставить команду для его `SimId` на ближайший тик. При исполнении команда SHALL менять цвет цели на цвет компонента `ClickColor`, если он присутствует. При перекрытии SHALL выбираться объект, нарисованный последним. Клик вне объектов и Shift + клик SHALL пропускать реакцию сущности.

#### Scenario: Клик по спутнику

- **WHEN** игрок включает аддон «Пустынный спутник» и кликает по спутнику
- **THEN** только спутник меняет цвет и продолжает движение

#### Scenario: Клик по объекту без реакции

- **WHEN** игрок кликает по объекту без `ClickColor`
- **THEN** цвет объектов сохраняется

#### Scenario: Клик по промежуточной позиции

- **WHEN** игрок кликает по видимому кругу движущегося спутника в кадре с интерполяцией
- **THEN** команда клика адресуется спутнику по его `SimId`
