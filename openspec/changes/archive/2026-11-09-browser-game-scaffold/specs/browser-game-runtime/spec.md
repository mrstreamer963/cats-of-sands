## Purpose

Позволяет запустить демонстрационную игровую сцену в браузере и увидеть результат обновления игрового мира.

## ADDED Requirements

### Requirement: Запуск демонстрационной сцены

Браузерное приложение SHALL запускать новую симуляцию с итоговой конфигурацией после нажатия «Запустить» и отображать её состояние на Canvas 2D.

#### Scenario: Запуск с базовой конфигурацией

- **WHEN** игрок запускает игру без аддонов
- **THEN** на холсте отображается один движущийся объект из базовой конфигурации

#### Scenario: Запуск с демонстрационным аддоном

- **WHEN** игрок запускает игру с демонстрационным аддоном
- **THEN** скорость базового объекта отличается от базовой, и на холсте отображается второй объект

#### Scenario: Повторный запуск

- **WHEN** игрок меняет выбор аддонов и запускает игру повторно
- **THEN** начинается новая симуляция из начального состояния с новым набором аддонов

### Requirement: Фиксированный шаг симуляции

Симуляция SHALL обновлять мир с фиксированным шагом, а отрисовка SHALL использовать снимок состояния после выполнения доступных шагов.

#### Scenario: Разная частота отрисовки

- **WHEN** две симуляции стартуют из одного состояния и выполняют одинаковое число шагов при разной частоте кадров
- **THEN** снимки содержат одинаковые позиции объектов
