## Context

Rust/WASM выполняет тики симуляции по 1/60 секунды. Canvas 2D рисует кадры с частотой браузера, поэтому один вызов обновления может выполнить несколько тиков или пропустить шаг до следующего кадра.

## Goals / Non-Goals

**Goals**

- Сглаживать координаты для Canvas, сохраняя игровые позиции на фиксированных тиках.
- Использовать одни координаты для рисования и проверки попадания курсора.

## Decisions

- Адаптер WASM сохраняет позиции перед последним шагом в пачке тиков. Это даёт соседние позиции даже при отрисовке реже 60 Гц. Снимки, снятые только по кадрам браузера, могли бы отстоять на несколько тиков.
- Для отрисовки WASM отдаёт отдельный снимок с текущей и предыдущей позициями. Браузер запрашивает его при смене тика и рассчитывает промежуточные координаты по доле шага из аккумулятора WASM.
- Начальный кадр использует текущую позицию для обоих концов интерполяции. При смене карты снимок отрисовки загружается заново.

## Risks / Trade-offs

- Интерполяция показывает движение с задержкой до одного тика.
- Скачок по горизонтали больше половины ширины сцены отображается сразу в конечной точке. Это убирает проход через экран при обычном переносе через край.
