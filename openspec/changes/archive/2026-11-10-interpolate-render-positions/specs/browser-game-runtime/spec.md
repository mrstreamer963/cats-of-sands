## MODIFIED Requirements

### Requirement: Фиксированный шаг симуляции

Ядро SHALL позволять выполнить заданное число тиков независимо от кадров браузера. Браузер SHALL преобразовывать время кадров в шаги по 1/60 секунды и отрисовывать сцену после выполнения доступных шагов. Координаты, радиус и скорость SHALL храниться в знаковом формате Q32.32. Сущности с `Position` и `Speed` SHALL двигаться независимо от наличия `Sprite`. Смещение за тик SHALL вычисляться целочисленным делением скорости на 60 с округлением к нулю.

#### Scenario: Разная частота отрисовки

- **WHEN** две симуляции стартуют из одного состояния и выполняют одинаковое число шагов при разной частоте кадров
- **THEN** снимки содержат одинаковые позиции объектов

#### Scenario: Пошаговый запуск без браузера

- **WHEN** хост просит ядро выполнить два тика с момента запуска
- **THEN** ядро выполняет тики 0 и 1, а следующим становится тик 2

#### Scenario: Кадр между тиками

- **WHEN** в двух последних завершённых тиках объект занимал разные позиции без перехода через край сцены
- **THEN** браузер линейно интерполирует позицию для отрисовки по доле времени, накопленной для следующего тика
- **AND** игровая позиция в снимке соответствует последнему завершённому тику

#### Scenario: Первый кадр

- **WHEN** браузер рисует сцену до первого тика
- **THEN** объект отображается в начальной позиции

#### Scenario: Переход через край сцены

- **WHEN** движущийся объект переносится через край сцены и разница горизонтальных координат превышает половину её ширины
- **THEN** браузер отображает текущую горизонтальную позицию сразу, без прохода через середину сцены

### Requirement: Реакция сущности на клик

Попадание SHALL определяться по положению объекта в последнем отрисованном кадре. Клик по видимому объекту SHALL поставить команду для его `SimId` на ближайший тик. При исполнении команда SHALL менять цвет цели на цвет компонента `ClickColor`, если он присутствует. При перекрытии SHALL выбираться объект, нарисованный последним. Клик вне объектов SHALL оставлять сцену без изменений.

#### Scenario: Клик по спутнику

- **WHEN** игрок включает аддон «Пустынный спутник» и кликает по спутнику
- **THEN** только спутник меняет цвет и продолжает движение

#### Scenario: Клик по объекту без реакции

- **WHEN** игрок кликает по объекту без `ClickColor`
- **THEN** цвет объектов сохраняется

#### Scenario: Клик по промежуточной позиции

- **WHEN** игрок кликает по видимому кругу движущегося спутника в кадре с интерполяцией
- **THEN** команда клика адресуется спутнику по его `SimId`
